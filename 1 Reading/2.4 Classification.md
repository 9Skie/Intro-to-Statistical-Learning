## Classification VS Regression

When we look at an ML problem, the variables that are given are either quantitative or qualitative.

- Quantitative variables represent numerical quantities, like a person's weight or income, they can be discrete or continuous.
- Qualitative variables represent categorical variables, representing $K$ different categories.

We generally refer to problems with a **quantitative response** as **regression problems**, and problems with a **qualitative response** as **classification problems**. 
- For example, predicting a house’s selling price is a regression problem, while predicting whether it will sell within a month is a classification problem.

The type of response guides our choice of learning method.

## The Classification Setting

Error in classification can no longer be simply defined as some numerical 'distance' between the predicted output $\hat{y}_i$ and the real output $y_i$. We can only evaluate on an error rate, the percent of classifications that are either correct or wrong for the outputs.
- The indicator $I(\hat{y}_i \neq y_i)$ equals $1$ when the prediction is incorrect and $0$ when it is correct. Averaging these indicators over $n$ observations gives the classification error rate:

$\text{Error rate} = \frac{1}{n}\sum_{i=1}^{n} I(\hat{y}_i \neq y_i)$.


To more formally define a classification problem, we can write it out as:

$P(Y = k \mid X = x)$

The probability that the response $Y$ belongs to class $k$, given that the input $X$ has the value $x$.


But... as we do not know this function at all, we have to estimate it using a function that we made up, called $\hat{f}$.

$\hat{f}_k(x) = \widehat{P}(Y = k \mid X = x)$


Once we have estimated the conditional probabilities, we predict the class with the highest estimated probability:

$\hat{y}(x) = \underset{k \in \{1,\ldots,K\}}{\arg\max}\; \hat{f}_k(x)$.

Here, $\arg\max$ means “return the class $k$ for which $\hat{f}_k(x)$ is largest.” 
- We evaluate the estimated probability for each class and select the class with the highest value.


We can visualize this prediction rule when we have two predictors. For example, imagine predicting whether a house will sell within a month using its floor area $X_1$ and asking price $X_2$. Our two classes are “sold within a month” and “not sold within a month.”

Each house becomes a point on a two-dimensional plot: its horizontal position represents its floor area, and its vertical position represents its asking price. The point’s color represents its actual class:
- orange for houses that sold within a month
- blue for those that did not
